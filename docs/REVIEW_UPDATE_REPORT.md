# 复盘页第一版改造与验收

验收日期：2026-11-25。

## 本地预览

- 地址：`http://127.0.0.1:5188/?view=review`，直接进入复盘页。
- 不带查询参数时，仍默认进入任务管理。

## 改造内容

- 增加本月完成、有完成记录的天数、单日最多完成三项摘要。
- 月历展示两条完成任务标题，更多记录显示数量；点击日期查看全部记录。
- 当日详情支持展开任务正文、切换前后日期；保留任务颜色。
- 颜色筛选同步作用于摘要、日历和详情。
- 既有 `calendar_demo_*` 且带有「【示例】」前缀的记录默认隐藏，可手动显示，始终不计入摘要。
- 桌面使用日历与详情双栏；窄屏上下排列；手机日历使用数量预览。
- 月历支持方向键选择日期，跨月切换保留可用日期，月底自动限制到目标月最后一天。
- 使用现有主题变量，支持浅色与暗色模式。
- 标题、正文、辅助文字统一使用 `el-text` 的标准尺寸；统计使用 `el-statistic`，日期切换与今天标记使用框架按钮和标签。
- 页面和任务详情使用 `el-scrollbar` 默认滚动条，移除页面原生滚动条及自定义字号、字间距、行高。

## 修改范围

- `web/src/components/ReviewCalendar.vue`：复盘布局、统计、日历与当日详情。
- `web/src/components/TaskBoard.vue`：任务详情与新增任务弹窗增加左右留白，标题、表单与底部按钮保持对齐；桌面端最大 24px，手机端最小 20px。
- `web/src/App.vue`：支持复盘直达参数，以及仅用于复盘的布局标记。
- `web/src/styles.css`：复盘在手机上的导航和内容区布局。
- `web/components.d.ts`：组件自动导入声明随构建更新。
- 本报告。

任务存储格式、存储键、任务操作、JSON 导入导出均未修改。宣传页及定时任务未修改。

## 验证记录

项目没有配置测试脚本。当前命令环境未提供 npm 可执行文件，使用原有构建脚本对应的 Node 入口完成检查：

```text
node node_modules/vue-tsc/bin/vue-tsc.js --noEmit -p web/tsconfig.json
node scripts/build-product-site.mjs
git diff --check
```

三项检查通过，完整产物生成到 `product-site/dist/`，App 位于 `/app/`。

## 统计配色调整

本月完成使用 Element Plus `primary` 蓝色，有完成记录使用 `success` 绿色，单日最多使用 `warning` 橙色。图标、标题与数字采用对应主题色，图标背景采用框架浅色变量；手机隐藏图标时，标题和数字仍保留三色区分。保留统计组件默认字号、单位辅助文字色及现有滚动条样式。
