# 真实 App 界面截图

本目录展示还原至改造前版本的实际 App，不包含此前已撤销的视觉改造。

- 来源：本地完整站点预览 `http://127.0.0.1:5181/app/`。
- 数据：该独立预览地址中的内置示例任务，不读取日常使用地址的数据。
- 尺寸：1440 × 1000。
- 文件：`tasks-desktop.jpg`、`review-desktop.jpg`、`reminders-desktop.jpg`。
- 日期：2026-11-25；复盘月份与示例日期由实际应用生成。

宣传页在手机上按比例展示同一张真实桌面截图，可点击打开大图。App 移动端改造及计划任务调整暂缓，不制作与实际功能不符的移动界面。

更新时，在独立预览地址打开实际 App，使用内置示例数据，关闭弹层与悬停提示，分别截取任务管理、复盘和健康提醒。随后运行 `npm run build:site` 复制资源。
